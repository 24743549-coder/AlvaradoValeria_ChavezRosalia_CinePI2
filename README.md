Sistema de Gestión de Asientos de Cine 

Proyecto integrador desarrollado en C# para la digitalización y administración automatizada de reservaciones de asientos de cine mediante el uso de matrices bidimensionales.

Integrantes del Proyecto

 Descripción del Proyecto

El sistema gestiona una sala de cine compuesta por una matriz de 30 asientos (5 filas × 6 columnas). Permite controlar en tiempo real la ocupación y disponibilidad de los espacios mediante una interfaz de consola modular e intuitiva.

Tecnologías Utilizadas

Lenguaje: C# (.NET Core / Framework)

IDE: Visual Studio 2022

Control de Versiones: Git & GitHub
